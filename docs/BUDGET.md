## 五、ROI分析 Return on Investment

### 假设条件
- CHP现有客户: ~1,200人
- 平均年消费/客户: $800
- 预计App注册率: 60% → 720用户
- 会员消费提升: +25% → 每用户年增 $200

### 收益估算 (首年)
| 收益来源 | 计算 | 金额 |
|---------|------|------|
| 会员消费增加 | 720人 × $200 | $144,000 |
| 数字化预约节省人工 | 10h/周 × $30 × 52 | $15,600 |
| 客户留存提升（减少流失） | 估算5% × 1200 × $800 | $48,000 |
| **年增收益合计** | | **$207,600** |

### 回报周期
```
投资回收期 = $325,227 ÷ $207,600 ≈ 18.6 个月
首年ROI = ($207,600 - $12,960) ÷ $338,187 × 100% ≈ 57.5%
```

## 六、预算控制机制

### 变更管理
- 预算变更 < $2,000: PM批准
- 预算变更 $2,000–$10,000: PM + 业主批准
- 预算变更 > $10,000: 正式变更请求，需书面批准

### 每月预算审查
- 人力成本实际 vs 计划对比
- 工具费用审查
- 预算燃尽图更新
- 下月费用预测

### 应急储备使用规则
- 应急储备 $42,421 仅用于不可预见的需求变更
- 每次使用需PM书面记录原因
- 若使用超过50%需通知业主
